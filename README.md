# Proyek Pengembangan dan Pengoperasian Sistem Machine Learning: Prediksi Usia Abalon

Nama: Sonny Ariady

| | Deskripsi |
| --- | --- |
| Dataset | Dataset yang digunakan adalah **Abalone Data Set** dari UCI Machine Learning Repository (4.177 baris data pengukuran fisik kerang abalon dengan 8 fitur: 1 kategorikal `Sex` dan 7 numerik `Length`, `Diameter`, `Height`, `Whole weight`, `Shucked weight`, `Viscera weight`, `Shell weight`, serta kolom target `Rings`). |
| Masalah | Penentuan usia abalon secara konvensional memerlukan pemotongan cangkang dan penghitungan cincin tahunan di bawah mikroskop oleh ahli yang bersifat destruktif terhadap sampel, memakan waktu, dan berbiaya tinggi. Diperlukan solusi otomasi untuk memprediksi kategori usia abalon (dewasa vs muda) secara non-destruktif hanya dari karakteristik fisik luarnya. |
| Solusi machine learning | Membangun sistem klasifikasi biner berbasis Deep Neural Network (DNN) menggunakan pipeline end-to-end TensorFlow Extended (TFX) dengan orchestrator Apache Beam (`BeamDagRunner`). Pipeline mengintegrasikan komponen CsvExampleGen (ingesti & pemisahan data train-eval 80:20), StatisticsGen & SchemaGen & ExampleValidator (validasi data dan skema), Transform (rekayasa fitur tf.Transform), Trainer (pelatihan model), LatestBlessedModelResolver & Evaluator (evaluasi berbasis ambang batas blessing), hingga Pusher (penyimpanan model siap serving). |
| Metode pengolahan | Rekayasa data awal meliputi penamaan kolom dataset mentah dan pembentukan label biner (`label = 1` jika `Rings > 9` [dewasa], dan `0` [muda]). Preprocessing fitur menggunakan TensorFlow Transform (`tft`) untuk mencegah *training-serving skew*: fitur kategorikal (`Sex`) diubah menjadi indeks vocabulary via `tft.compute_and_apply_vocabulary`, 7 fitur numerik distandarisasi menggunakan z-score via `tft.scale_to_z_score`, dan label diteruskan secara deterministik. Pembagian data train dan eval (80:20) dilakukan menggunakan hash-bucket pada CsvExampleGen. |
| Arsitektur model | Arsitektur Deep Neural Network (DNN) terintegrasi `tf.Transform`: Input layer menerima fitur kategorikal ter-encode yang dialirkan ke Embedding layer (8 dimensi) lalu di-Flatten, digabungkan bersama 7 fitur numerik terstandarisasi melalui Concatenate layer, dialirkan ke 2 Hidden Dense layer berturut-turut (64 dan 32 neuron) dengan aktivasi ReLU serta Dropout (0.2) untuk regularisasi, dan diakhiri dengan Dense layer 1 unit beraktivasi Sigmoid untuk menghasilkan probabilitas kelas dewasa. Model dikompilasi menggunakan optimizer Adam (learning rate 0.001), loss binary_crossentropy, serta metrik accuracy dan AUC pada komponen Trainer. |
| Metrik evaluasi | Evaluasi model dilakukan menggunakan TensorFlow Model Analysis (TFMA) pada komponen Evaluator dengan metrik: ExampleCount, BinaryAccuracy, AUC (Area Under ROC Curve), Precision, dan Recall. Pengujian ambang batas validasi (*blessing*) yang dikonfigurasi pada Evaluator adalah `BinaryAccuracy` dengan `lowerBound: 0.5` (`valueThreshold >= 0.5`) pada dataset evaluasi sebelum model diizinkan di-push ke tahap produksi. |
| Performa model | Model berhasil memenuhi ambang batas validasi dan dinyatakan **BLESSED** oleh komponen Evaluator pada 880 sampel data evaluasi dengan performa: BinaryAccuracy mencapai **79.77%** (0.7977, melampaui ambang batas validasi lowerBound 0.5), AUC mencapai **87.06%** (0.8706), Precision **78.88%** (0.7888), Recall **80.69%** (0.8069), serta status validasi `validation_ok: true`. Model yang lolos validasi ini otomatis di-push oleh komponen Pusher ke direktori serving (`serving_model/`). |
| Opsi deployment | Model di-deploy menggunakan container resmi TensorFlow Serving (`tensorflow/serving:latest`) pada platform komputasi cloud Railway. Serving container menjalankan binary `tensorflow_model_server` yang melayani inferensi REST API berkinerja tinggi, menyediakan endpoint metadata model, serta mengekspos metrik performa native melalui konfigurasi monitoring protobuf (`monitoring/prometheus.config`). |
| Web app | Tautan deployment TensorFlow Serving aktif di Railway:<br>- Endpoint Metadata Model: [https://abalone-mlops-dicoding-production.up.railway.app/v1/models/abalone-model/metadata](https://abalone-mlops-dicoding-production.up.railway.app/v1/models/abalone-model/metadata)<br>- Endpoint Prediksi REST API: [https://abalone-mlops-dicoding-production.up.railway.app/v1/models/abalone-model:predict](https://abalone-mlops-dicoding-production.up.railway.app/v1/models/abalone-model:predict)<br>- Endpoint Metrik Prometheus: [https://abalone-mlops-dicoding-production.up.railway.app/monitoring/prometheus/metrics](https://abalone-mlops-dicoding-production.up.railway.app/monitoring/prometheus/metrics)<br>Bukti verifikasi deployment tersimpan pada berkas tangkapan layar: `sonnyariady-deployment.png`. |
| Monitoring | Pemantauan sistem machine learning dilakukan menggunakan Prometheus dengan scraping berkala dari endpoint metrik TF Serving `/monitoring/prometheus/metrics`. Metrik yang dipantau meliputi throughput request (`:tensorflow:serving:request_latency_count`), latensi eksekusi (`:tensorflow:serving:runtime_latency_count`), dan status load model (`:tensorflow:cc:saved_model:load_attempt_count`). Hasil eksekusi query metrik TF Serving pada Prometheus UI terbukti sukses menghasilkan series aktif (query `:tensorflow:serving:request_latency_count` sukses menampilkan 11 request prediksi terlayani dan 12 request total). Bukti hasil query metrik sukses tersimpan pada berkas tangkapan layar: `sonnyariady-monitoring.png` (serta salinannya di `monitoring/sonnyariady-monitoring.png`). |
